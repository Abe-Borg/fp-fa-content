# specs

Master specification language as markdown, one CSI section per file. The everyday path appends up to 12 of these files, README excluded, and only the first 4,000 characters of each. Twelve covers the section set below. This README is the folder guide and is not a spec.

Anything the model writes from these notes is still a draft. The engineer of record verifies it before it is issued. Do not put an API key, a job name, a client name, a personal name, or a vendor catalog in this folder. When a calc tool returns a figure, that figure governs the issued number. Do not copy another hall's gallons, rated pump pressure, zone count, or panel program.

## Section identity

Double-interlock preaction is CSI 21 13 19. Dry pipe is CSI 21 13 16. A double-interlock or preaction draft that carries the dry-pipe number is a mislabel. Retitle it 21 13 19. Do not move dry-pipe requirements onto 21 13 19 to correct the number.

The authoring catalog these notes were distilled from allowed single-interlock inside the preaction section and carried a clean-agent section. Neither is ingested. Single-interlock and non-interlock are comparison-only. Foam, clean agent, water mist, and deluge are out of scope. Do not author those sections. A jurisdiction outside the stated NFPA, IBC, and IFC basis is out of scope.

Company systems here: wet pipe, dry pipe, and double-interlock preaction, plus pumps, private mains, Class I standpipes, common work, and the Division 28 fire alarm those systems need. Nitrogen and compressors are articles inside the dry and double-interlock sections.

## How a number is written

Cite the section and the edition. An unamended 2024 I-Code floor is not the latest published edition. Do not cite a latest edition as the code minimum unless the authority having jurisdiction adopted it. A value the tools did not return is ASSUMED or a cited screen. It is not a calculated zone result. Verify judgment calls with the engineer of record.

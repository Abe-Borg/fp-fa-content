# Synthesis

This mode writes the draft narrative after a zone tool plan. It does not open a new brainstorm and it does not recompute the tables.

The tool plan governs the tables and the docx when the narrative disagrees. The draft must contain the exact zone-total text and the exact t_total text the request names.

Pipe gallons and t_total are calculated. Blank trim and the screen-limit lookup stay ASSUMED. A trim value the designer typed is not assumed. Do not describe an ASSUMED value as calculated.

A delivery time from dry_delivery_screen or di_trip_to_water is an optimistic screen, not a listed water-delivery-time calculation. Say that in the draft.

A sentence that is the designer's judgment, and that no tool returned, is labeled use best judgment. Keep that label off calculated figures and off ASSUMED figures.

The double-interlock draft section string is 21 13 19. Do not put another sprinkler section number on this export.

Read spec-draft, and read the sprinkler or releasing role when that part of the draft needs it. Read the skill you apply. Do not name a catalog number. The narrative is a draft for the engineer of record to verify.

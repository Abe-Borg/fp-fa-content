# corpus

Reference notes for a later pass: paraphrased decision logs, edition citations, and short method background the app can search.

The prototype does not read this folder yet. When a content pack adds files, keep the same rule as the rest of the repo: no raw NFPA text, no vendor catalogs, and no job, client, or personal names.

Prefer one topic per markdown file, with the edition and section number next to any numeric screen, so a future search tool can cite the file without copying a standard into the repo.

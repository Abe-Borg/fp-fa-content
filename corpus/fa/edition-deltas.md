# NFPA 72 edition pins and section moves

The enforced edition is the one the adopted building or fire code references. It is often one cycle behind the latest book. IBC 2021 and IFC 2021 reference NFPA 72-2019. IBC 2024 and IFC 2024 reference NFPA 72-2022. NFPA 1-2024 §2.2 references NFPA 72-2022. NFPA 1-2018 §2.2 references NFPA 72-2016. A 2025 citation under a 2024 I-Code needs an amendment or an authority acceptance.

When the building code and the fire code are different cycles, they can point at different NFPA 72 editions. Meet the stricter value where the two editions differ, and confirm which instrument governs. Do not copy a city adoption table onto a new site. Local amendments move, and several city names are outside this pack.

There is no single 2022-to-2025 crosswalk. Compare the section, then name the edition.
